## 3. Mom Test 결과 (STEP 1 — 10점 수정본)

**자가 채점:** 10 / 10  
**상세 워크북:** [Prompt/mom-test-workbook-session3.md](../Prompt/mom-test-workbook-session3.md)

### 페르소나
수업 중 선생님이 **feet·yard·cubit** 등 **길이 단위 변환**을 **즉석에서** 물어보는 환경의 **학습자**. 비율을 **머릿속에 두기 어렵고**, 질문할 때마다 **검색·계산·침묵**으로 버틴다.

### 진짜 문제 (한 문장)
수업 중 선생님이 길이 단위 변환을 물을 때마다 **단위·비율이 기억나지 않아 매번 막히고**, 검색·계산에 **5분 넘게** 걸리거나 **침묵**하게 되며 **스트레스와 창피함**을 겪는다.

### Mom Test 증거 3줄
1. **2.5m→feet** 질문에 **검색 5분+** — 결과는 **1m 기준**만 있어 **계산기로 2.5배** 계산 후에야 답함.
2. **1 cubit=? meter** 질문에 **침묵** → 다른 학생이 답 → **창피**; 수업 후 검색해 **0.4572m**를 알았지만 **머릿속만** 기억.
3. **feet·yard·cubit** 질문이 **반복**되는데, **매번** 비율이 기억나지 않아 막힘(생소 단위만이 아님).

### Mom Test 채점 체크리스트

| 항목 | 충족 |
|------|------|
| 미래 가정 없음 | ✓ |
| 과거 행동·시간·실수 구체성 | ✓ |
| 진짜 문제에 솔루션名 없음 | ✓ |
| 표면 문제와 진짜 문제 분리 | ✓ |

### Pain Points (솔루션 전)
1. **기억 실패** — feet·yard·cubit 비율이 매번 기억나지 않음
2. **즉답 압박** — 수업 중 5분+는 스트레스
3. **검색 한계** — 1m 기준만 → 2.5m 수동 계산
4. **침묵·창피** — cubit 등에서 답 못함 → 다른 사람이 답

### 표면 문제 (이번에 하지 않을 것)
- 면적·무게·온도 등 다른 카테고리
- 풀 모바일 UI(키패드·전 탭) — pain은 기억·즉답
- JSON·동적 등록·CSV 출력 (README 후속)
- “앱 만들기”“TDD 하기” 등 방법론 자체

### 개발에 반영할 시사점
- Entity `convert_units` — `validate_lines`와 동형 계약 (`status`, `conversions`, `failed_fields`)
- **한 값 입력 → 등록 4단위 즉시 변환** (SC-1~3 ↔ FR-CONV-02~04)
- **cubit** 등록 (`1 cubit = 0.4572 meter`)
- 입력 검증 FR-CONV-01 (음수·unknown unit → `invalid`)

## 4. 세션 3 — R-G-I-O · Entity 계약

**SSOT:** [docs/PRD.md](../docs/PRD.md)  
**워크북:** [Prompt/mom-test-workbook-session3.md](../Prompt/mom-test-workbook-session3.md)

### R-G-I-O

| | 내용 |
|---|------|
| **Role** | **Entity** — `convert_units(unit, value)` 순수 변환. Boundary=`단위:값` 파싱, Control=흐름·출력(후속). |
| **Goal** | meter 기준 **등록 4단위**(meter/feet/yard/cubit) 변환 결과를 **한 번에** 구조화 반환한다. |
| **Input** | Entity: `unit: str`, `value: float` (Boundary에서 `meter:2.5` 등 파싱). `value ≥ 0`, 등록 unit만 success. |
| **Output** | `{ "status", "conversions", "failed_fields" }` — `validate_lines`의 `{ status, failed_lines }` 패턴 |

### Entity API (`convert_units`)

```python
result = convert_units(unit, value)
# result["status"]        → "success" | "invalid"
# result["conversions"]   → {"meter", "feet", "yard", "cubit"} (success 시)
# result["failed_fields"] → [] | ["value"] | ["unit"]  (invalid 시)
```

### 기준 단위 · 변환 상수 (마법 상수)

MagicSquare **34**에 대응 — **meter = 1** + 고정 비율 3개. 상세: [docs/PRD.md § 기준 단위 · 변환 상수](../docs/PRD.md#기준-단위--변환-상수-마법-상수)

| 상수 | 값 | 의미 |
|------|-----|------|
| (앵커) meter | **1** | 공통 기준 |
| `FEET_PER_METER` | **3.28084** | 1 m = 3.28084 ft |
| `YARDS_PER_METER` | **1.09361** | 1 m = 1.09361 yd |
| `METERS_PER_CUBIT` | **0.4572** | 1 cubit = 0.4572 m |

### 성공 기준 · FR · Test ID
