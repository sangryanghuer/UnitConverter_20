## 1. 요약

수업 중 선생님이 **길이 단위 변환**을 즉석에서 물을 때, 학습자는 **비율 기억 실패**로 매번 막히고 **검색·수동 계산·침묵**으로 버틴다.  
Mom Test 인터뷰로 과거 행동을 확인한 결과, pain은 **앱·TDD·UI 꾸미기**가 아니라 **기억·즉답·시간·창피**에 집중된다.  
이 보고서는 그 증거를 **문제 정의**로 고정하고, 구현 요구사항은 [docs/PRD.md](../docs/PRD.md)로 위임한다.

---

## 2. 페르소나

수업 중 선생님이 **feet·yard·cubit** 등 **길이 단위 변환**을 **즉석에서** 물어보는 환경의 **학습자**.  
비율을 **머릿속에 두기 어렵고**, 질문할 때마다 **검색·계산·침묵**으로 버틴다.

---

## 3. 진짜 문제 (한 문장)

> 수업 중 선생님이 길이 단위 변환을 물을 때마다 **단위·비율이 기억나지 않아 매번 막히고**, 검색·계산에 **5분 넘게** 걸리거나 **침묵**하게 되며 **스트레스와 창피함**을 겪는다.

---

## 4. Mom Test 증거

| # | 과거 행동 (증거) |
|---|------------------|
| ① | **2.5m→feet** 질문에 **검색 5분+** — 결과는 **1m 기준**만 있어 **계산기로 2.5배** 계산 후에야 답함. |
| ② | **1 cubit=? meter** 질문에 **침묵** → 다른 학생이 답 → **창피**; 수업 후 검색해 **0.4572m**를 알았지만 **머릿속만** 기억. |
| ③ | **feet·yard·cubit** 질문이 **반복**되는데, **매번** 비율이 기억나지 않아 막힘(생소 단위만이 아님). |

**보완 인터뷰 (Q9 수정):** feet·yard도 cubit처럼 침묵이 아니라 **매번 막혀**, **단위가 잘 기억이 안 남**.

상세 Q&A: [Prompt/mom-test-interview.md](../Prompt/mom-test-interview.md)

## 6. Pain Points (솔루션 전)

| # | Pain | Mom Test 연결 |
|---|------|---------------|
| P1 | **기억 실패** — feet·yard·cubit 비율이 매번 기억나지 않음 | ③ |
| P2 | **즉답 압박** — 수업 중 5분+는 스트레스 | ① |
| P3 | **검색 한계** — 1m 기준만 → 2.5m 수동 계산 | ① |
| P4 | **침묵·창피** — cubit 등에서 답 못함 → 다른 사람이 답 | ② |

## 7. 표면 문제 — 이번에 하지 않을 것

| 표면 (X) | 이유 |
|----------|------|
| 면적·무게·온도 등 **다른 카테고리** | pain은 **수업 길이 단위**에서만 확인됨 |
| **풀 모바일 UI**(키패드·전 탭) | pain은 **기억·즉답**; look & feel은 후속 Track |

| 검색/API 품질 개선 | 과거 pain은 **내 기억·계산** 쪽 |

## 8. 문제 → 요구사항 연결 (R-G-I-O)

| | 내용 |
|---|------|
| **Role** | **Entity** — `convert_units(unit, value)` 순수 변환. **Boundary** — `단위:값` 파싱. **Control** — 흐름·출력(후속). |
| **Goal** | meter 기준 **등록 4단위**(meter/feet/yard/cubit) 변환 결과를 **한 번에** 구조화 반환. |
| **Input** | `unit: str`, `value: float` (`value ≥ 0`, 등록 unit). Boundary: `meter:2.5`, `cubit:1` 등. |
| **Output** | `{ status, conversions, failed_fields }` — success 시 4단위 dict, invalid 시 원인 필드 |

| **SC-2** | `cubit:1` → 전 단위 (침묵·수업 후 검색 불필요) | ② | FR-CONV-03 | D-CONV-02 |

## 10. 개발 시사점

1. **한 값 입력 → 등록 4단위 즉시 변환** — 매번 비율을 기억·검색할 필요 제거 (SC-1~3).
2. **cubit 등록** — Mom Test에서 확인된 `1 cubit = 0.4572 meter` 반영.
3. **입력 검증** — 음수·unknown unit은 명확히 `invalid` (FR-CONV-01).
4. **앵커 meter = 1** — 모든 단위를 meter로 통일 후 환산 (PRD 마법 상수).
